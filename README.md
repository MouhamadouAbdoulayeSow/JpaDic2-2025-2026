# JPA Mapping Exercises – DIC2 2025-2026

**Domains:** Software · Data

Java Persistence API exercises from the DIC2 course at École Polytechnique de Thiès.

## Content
- Entities `Personne`, `Etudiant`, `CarteEtudiant`, `Classe`, `Niveau`, `Salle`.
- One-to-one, one-to-many and many-to-many relationship mappings.
- An entity listener that logs lifecycle events.
- Persistence unit configured in `META-INF/persistence.xml`.

## Stack
Java · JPA / Hibernate · Maven

## Run
Configure the database in `persistence.xml`, then run `Main` or `TestOneToOne`.
